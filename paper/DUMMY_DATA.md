# Dummy-Data Replacement Checklist

Every numeric result in the manuscript is a **placeholder** chosen to be
internally consistent and plausible. Search the `.tex` sources for `[DUMMY]`
and `[PLACEHOLDER]` comments — each marks a block to replace. This file lists
them all, with the experiment that produces the real value.

## Golden rules when replacing

1. **Keep the numbers consistent everywhere.** The same values appear in the
   abstract, intro (contributions), results tables, figures, discussion, and
   conclusion. Grep for the old value (e.g. `4.1`) after replacing a table.
2. **Regenerate figures after editing the arrays** in
   `scripts/plot_paper_figures.py`:
   `python scripts/plot_paper_figures.py`
3. Recompute derived claims: "26% relative reduction", "29% relative",
   "35–45% relative", "$p < 0.01$", "12 of 19 attacks", gate statistics
   (0.63 / 0.31), cosine similarities (0.84 / 0.61).
